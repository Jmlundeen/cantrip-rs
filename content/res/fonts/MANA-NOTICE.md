# Mana icon font

`mana.ttf` is the [Mana](https://github.com/andrewgioia/mana) icon font by Andrew Gioia,
taken from the `master` branch on 2026-09-13 (the font declares itself v1.18.0; the last
tagged release at that date was v1.17.1).

The font is licensed under the SIL Open Font License 1.1
(<https://scripts.sil.org/OFL>). The project's CSS, LESS and Sass files, which are not
included here, are MIT licensed. The codepoints the client uses are listed in
`ManaSymbols.cs`; the full map is `css/mana.css` upstream.

The symbols themselves are Wizards of the Coast's, used here as unlicensed fan content.
